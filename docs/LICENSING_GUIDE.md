# Licensing & Protection Guide

## 🛡️ Protection Options for Your Mechanics

### Option 1: Software Licensing (What We've Set Up)

**Current License Type:** MIT with Commercial Restriction

This license allows:

- ✅ Free use for learning, research, personal projects
- ✅ Modification and distribution (non-commercial)
- ❌ Commercial use without license/donation
- ❌ Use in revenue-generating games

### Option 2: Patent Protection (Strongest)

**Cost:** $30,000-$150,000 total
**Protection:** 20 years exclusive rights
**Enforcement:** Can sue for damages

**Steps:**

1. File provisional patents ($3,000-$5,000) - Immediate
2. Professional patent search ($2,000-$3,000)
3. Full utility patents ($30,000-$45,000)
4. International (PCT) filing ($50,000-$100,000)

### Option 3: Trade Secret

**Cost:** $0
**Protection:** As long as secret is maintained
**Risk:** Once disclosed, no protection

**Not recommended** for open-source projects.

## 📋 License Compliance Monitoring

### Methods to Detect Unauthorized Use

1. **Google Alerts**

   - Set up alerts for your project name
   - Monitor for "Markov chain slot", "Fibonacci evolution slot", etc.

2. **GitHub Search**

   - Search for unique function names
   - Search for unique variable names

3. **Code Similarity Tools**

   - MOSS (Measure of Software Similarity)
   - Copyscape (for documentation)

4. **Gaming Industry Monitoring**
   - Watch for new slots with similar mechanics
   - Monitor game providers' releases

### Enforcement Actions

1. **Friendly Reminder** - Email requesting compliance
2. **DMCA Takedown** - For GitHub/hosted code
3. **Cease & Desist** - Legal letter
4. **Patent Infringement Claim** - If patents filed
5. **Lawsuit** - For significant damages
