## 🎮 Mechanics Overview

### ⚡ Transform Mechanics (Markov Chains)

Symbols transition between states using probability matrices.

```python
States: LOW → MEDIUM → HIGH → WILD → SUPER
Trigger Rate: 20%
Expected Payout: 58.8x average
Formula: πP = π (steady-state equilibrium)
```

### 🧬 Evolution Mechanics (Fibonacci/Golden Ratio)

Symbols evolve through 10 levels with Fibonacci multipliers.

```python
Levels: 0-10
Multipliers: 1x → 89x (Fibonacci sequence)
Probability: P(n) = 0.50 / φⁿ (Golden Ratio decay)
φ = 1.618033988749895
```

### ⏰ Time Travel Mechanics (Wave Functions)

Retrieve past wins and predict future outcomes.

```python
Past Retrieval: P = e^(-0.2 × spins_ago)
Future Accuracy: A = e^(-0.1 × spins_ahead)
Wave: ψ(t) = 10|sin(0.5t)|e^(-0.1t)
```

### 🔄 Morphing Mechanics (Bezier Curves)

Smooth symbol transformations using cubic interpolation.

```python
States: BASIC → ENHANCED → PREMIUM → ELITE → LEGENDARY
Bezier: B(t) = (1-t)³P₀ + 3(1-t)²tP₁ + 3(1-t)t²P₂ + t³P₃
Evolution: Conway's Game of Life rules
```
