# Examples

This directory contains example implementations of the innovative slot mechanics.

## Files

- `demo_game.py` - Interactive demo showcasing all four mechanics

## Running the Demo

```bash
cd innovative-mechanics
python examples/demo_game.py
```

## What You'll See

The demo runs 10 spins showing:

- ⚡ Transform - Symbols changing states via Markov chains
- 🧬 Evolution - Fibonacci multipliers activating
- ⏰ Time Travel - Past wins retrieved, future boosts applied
- 🔄 Morphing - Bezier curve transformations
